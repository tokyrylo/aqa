Практика: программа «Угадай число»

Что делает программа:

  • Компьютер выбирает число от 1 до 10.

  • Пользователь пытается угадать число.

  • Программа говорит, угадал или нет.

  • Можно добавлять цикл, чтобы дать несколько попыток.

1. Простейшая версия без цикла

import random  # чтобы выбрать случайное число

secret_number = random.randint(1, 10)  # случайное число от 1 до 10
guess = int(input("Угадайте число от 1 до 10: "))

if guess == secret_number:
    print("Поздравляем! Вы угадали число!")
else:
    print("Попробуйте ещё раз. Загаданное число было:", secret_number)

Что здесь используется:

  • Переменные: secret_number, guess

  • Ввод данных: input()

  • Арифметика и сравнение: ==

  • Условие: if / else

  • Модуль random для случайного числа

2. Улучшенная версия с циклом и подсказками

import random

secret_number = random.randint(1, 10)
attempts = 3  # количество попыток

print("Угадайте число от 1 до 10. У вас 3 попытки!")

while attempts > 0:
    guess = int(input("Введите число: "))

    if guess == secret_number:
        print("Поздравляем! Вы угадали число!")
        break  # выходим из цикла, если угадали
    elif guess < secret_number:
        print("Слишком маленькое число!")
    else:
        print("Слишком большое число!")

    attempts -= 1  # уменьшаем количество попыток

if attempts == 0:
    print("Попытки закончились. Загаданное число было:", secret_number)

Что здесь дополнительно используется:

  • Цикл while для повторных попыток

  • Логические операторы (через if / elif / else)

  • Арифметика для уменьшения attempts

3. Мини-задание для новичка

  • Попробуй сначала написать простую версию с одной попыткой.

  • Потом усложни с тремя попытками.

  • Попробуй добавить подсказку «больше/меньше».

  • После этого можешь попробовать увеличить диапазон чисел до 20.
