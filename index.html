Добро пожаловать в документацию Python для начинающих AQA

Эта документация предназначена для новичков, которые хотят изучать Python с упором на автоматизацию тестирования.
Если вы раньше писали только в Word или использовали браузер, здесь всё объяснено простыми словами, с примерами и мини-упражнениями.

Цель

Научить вас:

  • Понимать основы Python: переменные, типы данных, операторы.
  • Создавать свои функции и использовать аргументы.
  • Писать программы с условиями и циклами.
  • Практиковаться на мини-упражнениях: калькуляторы, угадай число и др.
  • Разрабатывать код, который можно тестировать через unit-тесты.

Структура документации

  1. Установка Python и IDE — как начать работать на Windows, Mac и Linux.
  2. Консоль и команды — запуск Python, работа с интерпретатором.
  3. Переменные и типы данных — строки, числа, логические значения.
  4. Операторы — арифметические, сравнения, логика.
  5. Ввод данных — input() и работа с пользовательскими данными.
  6. Управляющие конструкции — if / else, циклы for и while.
  7. Функции — как создавать, использовать аргументы и возвращаемые значения, *args, **kwargs.
  8. Практика — мини-упражнения и простые проекты для закрепления знаний.

Начните с первого раздела и постепенно продвигайтесь вперёд.
Всё объяснено с примерами, поэтому даже без опыта программирования вы сможете написать рабочий код.
