Функция — что это и зачем она нужна

Что такое функция:

  • Функция — это названный блок кода, который делает одно конкретное действие.

  • Представь её как мини-машинку, которая выполняет задачу и может возвращать результат.

Зачем нужна функция:

  • Не повторять один и тот же код снова и снова.

  • Делить программу на логические части, чтобы было проще читать и понимать.

  • Легко тестировать и использовать повторно.

1. Простая функция

def say_hello():
    print("Привет!")

Что здесь:

  • def — ключевое слово для создания функции

  • say_hello — название функции

  • () — функция может принимать параметры (пока пусто)

  • print("Привет!") — код, который выполняется при вызове функции

Вызов функции:

say_hello()

Результат:

Привет!

2. Функция с параметрами

def greet_user(name):
    print("Привет,", name)

greet_user("Ира")
greet_user("Петя")

Результат:

Привет, Ира
Привет, Петя

Зачем параметры:

  • Чтобы функция могла работать с разными данными, не переписывая код.

3. Функция, которая возвращает значение

def add_numbers(a, b):
    return a + b

result = add_numbers(5, 7)
print("Сумма:", result)

Результат:

Сумма: 12

Зачем return:

  • Чтобы функция отдавала результат, который можно использовать в других частях программы.

4. Примеры из жизни

  • Функция «Сварить чай» → делает один конкретный процесс, можно вызывать снова и снова.

  • Функция «Посчитать сумму двух чисел» → работает с любыми числами, не переписывая код каждый раз.

5. Мини-упражнение

  • Создай функцию say_hello()без параметров, которая печатает «Привет!».

  • Создай функцию greet_user(name), которая приветствует пользователя по имени.

  • Создай функцию multiply(a, b), которая возвращает произведение двух чисел.

  • Вызови функции с разными значениями и выведи результат на экран.
