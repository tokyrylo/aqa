Лямбда-функции в Python

Лямбда-функция— это анонимная (без имени) функция, которую можно записать в одну строку. Она создаётся с помощью ключевого слова lambda.

Синтаксис:

lambda аргументы: выражение

Пример:

square = lambda x: x ** 2
print(square(4))  # 16

То же самое через обычную функцию:

def square(x):
    return x ** 2

Когда использовать?

Лямбда-функции применяются там, где нужно быстро описать простую логику и не хочется создавать отдельную def-функцию.

Часто встречается в AQA:

  • при обработке данных из API,

  • при фильтрации или сортировке результатов,

  • в callback-функциях.

Примеры использования

Фильтрация данных (filter)

numbers = [1, 2, 3, 4, 5, 6]
even = list(filter(lambda x: x % 2 == 0, numbers))
print(even)  # [2, 4, 6]

Преобразование списка (map)

numbers = [1, 2, 3]
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9]

Сортировка по ключу (sorted)

users = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 30},
    {"name": "Charlie", "age": 20}
]

sorted_users = sorted(users, key=lambda u: u["age"])
print(sorted_users)
# [{'name': 'Charlie', 'age': 20}, {'name': 'Alice', 'age': 25}, {'name': 'Bob', 'age': 30}]

Быстрая проверка в автотесте

status_codes = [200, 201, 404, 500]
assert all(map(lambda code: code < 500, status_codes)), "Найден серверный баг"

Ограничения лямбда-функций

  • В lambda можно писать только одно выражение (нельзя много строк).
  • Нельзя использовать конструкции if-elif-elseс блоками (только тернарный оператор).
  • Читаемость кода может пострадать, если злоупотреблять.
