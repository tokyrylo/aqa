Область видимости переменных в Python

Область видимости (scope) — это то, где переменная "видна" и может использоваться.

В Python действует правило LEGB:

  • L (Local) — локальная область функции.

  • E (Enclosing) — область внешней функции (замыкания).

  • G (Global) — глобальные переменные модуля.

  • B (Built-in) — встроенные имена Python (len, print и др.).

1. Локальная область (Local)

Переменная, созданная внутри функции, доступна только в ней.

def test_case():
    result = "passed"  # локальная переменная
    print("Результат:", result)

test_case()
# print(result)  # ❌ Ошибка! Вне функции переменная недоступна

2. Глобальная область (Global)

Переменные, объявленные вне функций, доступны везде.

status = "ready"  # глобальная переменная

def run_test():
    print("Статус теста:", status)

run_test()
print("Вне функции:", status)

3. Изменение глобальной переменной внутри функции

По умолчанию внутри функции нельзя изменять глобальную переменную. Нужно явно указать global.

counter = 0

def increase():
    global counter
    counter += 1

increase()
print(counter)  # 1

4. Вложенные функции и nonlocal (Enclosing)

Переменная внешней функции доступна во вложенной. Чтобы её изменить — используем nonlocal.

def outer():
    attempts = 0

    def inner():
        nonlocal attempts
        attempts += 1
        print("Попытка:", attempts)

    inner()
    inner()

outer()

5. Built-in

Это встроенные функции Python. Если назвать переменную как встроенную функцию — можно "сломать" код.

len = 10  # ❌ затёрли встроенную функцию
print(len(["a", "b"]))  # Ошибка!
