# Циклы for и while — повторение действий

**Что это такое**:

- Цикл — это способ повторять один и тот же блок кода несколько раз.

- Вместо того, чтобы писать одну и ту же команду десять раз, используем цикл.

**Зачем**:

- Чтобы программа могла делать одно и то же действие много раз автоматически.

- Например, печатать все имена друзей, считать числа, проверять список покупок.

## 1. Цикл `for`

**Когда использовать**: когда известно, сколько раз повторять или у нас есть список элементов.

```python
fruits = ["яблоко", "банан", "киви"]

for fruit in fruits:
    print("Я люблю", fruit)
```

Результат:

```bash
Я люблю яблоко
Я люблю банан
Я люблю киви
```

**Пример с числами:**


```python
for i in range(1, 6):
    print("Номер:", i)
```
Результат:

```bash
Номер: 1
Номер: 2
Номер: 3
Номер: 4
Номер: 5
```

## 2. Цикл `while`

**Когда использовать**: когда не знаем заранее, сколько раз повторять, но есть условие.

```python
count = 1

while count <= 5:
    print("Счётчик:", count)
    count += 1   # увеличиваем count на 1 каждый раз
```
Результат:

```bash
Счётчик: 1
Счётчик: 2
Счётчик: 3
Счётчик: 4
Счётчик: 5
```

Важно:

- Без увеличения `count` цикл будет бесконечным.

- `while` работает до тех пор, пока условие `True`.

## 3. Примеры из жизни

 - `for`: перебираем список покупок и печатаем все элементы.

 - `while`: пока батарея телефона > 0, продолжаем звонить.

 - Можно использовать `for` и `while` вместе с условиями `if` для сложных задач.
