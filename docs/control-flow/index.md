# Управляющие конструкции

**Два слова**: «Контроль потока».

**Что это такое**:

- Это инструкции, которые решают, что программа делает дальше.

- Позволяют выбирать действия или повторять их несколько раз.

**Зачем**:

- Чтобы программа могла принимать решения (например, проверять возраст пользователя).

- Чтобы не повторять одно и то же вручную, а делать циклы.

**Примеры из жизни**:

- Если на улице дождь → взять зонт, иначе идти без него.

- Пока заряд батареи > 0 → телефон работает.
