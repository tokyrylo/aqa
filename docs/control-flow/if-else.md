# if / else — принятие решений

**Что это такое**:

- `if / else` — это способ **сказать компьютеру: «если условие верно — делай одно, иначе — делай другое»**.

- Проще говоря, это разветвление пути программы.

**Зачем**:

- Чтобы программа могла реагировать на разные ситуации.

- Например, проверять возраст пользователя, наличие денег, результаты тестов и т.д.

## **1. Синтаксис**

```python
if условие:
    # блок кода, выполняется если условие True
else:
    # блок кода, выполняется если условие False
```

## **2. Примеры из жизни**

**Пример 1: проверка возраста**

```python
age = 20

if age >= 18:
    print("Вы взрослый!")
else:
    print("Вы ещё ребёнок!")
```
Результат:

```bash
Вы взрослый!
```

**Пример 2: проверка погоды**

```python
is_raining = True

if is_raining:
    print("Возьмите зонт!")
else:
    print("Можно идти без зонта")
```
Результат:

```bash
Возьмите зонт!
```

**Пример 3: проверка логического значения**

```python
likes_pizza = False

if likes_pizza:
    print("Делаем пиццу!")
else:
    print("Делаем салат!")
```

Результат:

```bash
Делаем салат!
```
