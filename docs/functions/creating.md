# Как писать свои функции

Функция — это блок кода, который делает одно конкретное действие, и его можно использовать многократно.

## 1. Синтаксис функции
```python
def имя_функции(параметры):
    """Докстринг — описание функции (необязательно)"""
    блок_кода
    return значение_если_нужно
```

Объяснение:

- `def` — ключевое слово, чтобы Python понял, что создаётся функция

- `имя_функции` — название (информативное, по правилам naming convention)

- `параметры` — данные, которые функция получает для работы

- `return` — то, что функция отдаёт, если нужно использовать результат


## 2. Правила хорошей функции

1. Название должно быть понятным

   - Плохо: `def f(a,b)`

   - Хорошо: `def calculate_sum(a, b)`

2. Делать одну вещь за раз

   - Функция «считает сумму» → не печатает и не спрашивает данные одновременно

3. Использовать параметры, а не «хардкодить» значения

   - Плохо: `def add_five(): return 5 + 7`

   - Хорошо: `def add_numbers(a, b): return a + b`

4. Если функция что-то возвращает, использовать `return`

   - Иначе функция вернёт `None`

## Мини-упражнение

- Напиши функцию `say_hello()`, которая печатает «Привет!»

- Напиши функцию `greet_user(name)`, которая приветствует пользователя по имени

- Напиши функцию `multiply(a, b)`, которая возвращает произведение двух чисел

- Вызови функции с разными значениями и выведи результат
