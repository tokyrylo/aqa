# Аргументы и возвращаемые значения функций

## 1. Аргументы (параметры)

**Что это**:

- Данные, которые мы передаём функции, чтобы она могла с ними работать.

- Это как ингредиенты для рецепта: без них нельзя приготовить блюдо.

Пример:

```python
def greet_user(name):
    print("Привет,", name)

greet_user("Ира")
greet_user("Петя")
```
- Здесь `name` — аргумент функции.

- Мы передаём `"Ира"` или `"Петя"`, и функция использует эти данные.

**Типы аргументов**

1. **Обязательные** — функция не запустится без них

```python
def add(a, b):
    return a + b

add(5, 7)  # OK
# add(5)  # Ошибка!
```
2. **Необязательные / с дефолтным значением**

```python
def greet_user(name="Гость"):
    print("Привет,", name)

greet_user()       # Привет, Гость
greet_user("Ира")  # Привет, Ира
```

## 3. *args — любое количество позиционных аргументов

**Что это**:

- Позволяет передавать функции **любое количество обычных аргументов** (по позиции).

- Аргументы собираются в кортеж внутри функции.

**Пример**:

```python
def sum_numbers(*args):
    total = 0
    for num in args:
        total += num
    return total

print(sum_numbers(1, 2, 3))       # 6
print(sum_numbers(5, 10, 15, 20)) # 50
```
- Можно передавать сколько угодно чисел.

- Внутри функции `args` — это кортеж `(1, 2, 3)`

## 4. **kwargs — любое количество именованных аргументов

**Что это**:

- Позволяет передавать функцию любое количество аргументов с именами.

- Аргументы собираются в словарь внутри функции.

**Пример**

```python
def greet_users(**kwargs):
    for name, greeting in kwargs.items():
        print(f"{greeting}, {name}!")

greet_users(Ira="Привет", Petya="Здравствуйте", Olga="Приветствую")
```
Результат:
```bash
Привет, Ira!
Здравствуйте, Petya!
Приветствую, Olga!
```
- Внутри функции `kwargs` — это словарь: `{'Ira': 'Привет', 'Petya': 'Здравствуйте', 'Olga': 'Приветствую'}`

## 5. Комбинирование обычных аргументов, *args и **kwargs

```python
def show_info(title, *args, **kwargs):
    print("Заголовок:", title)
    print("Аргументы:", args)
    print("Ключевые аргументы:", kwargs)

show_info("Информация", 1, 2, 3, name="Ира", age=20)
```
**Результат**:

```bash
Заголовок: Информация
Аргументы: (1, 2, 3)
Ключевые аргументы: {'name': 'Ира', 'age': 20}
```
**Когда это полезно**:

- Когда не знаешь заранее, сколько данных придёт в функцию

- Для написания универсальных функций (например, логгеры, обработчики данных)

- Для чистого и читаемого кода без повторений

## 6. Возвращаемое значение (return)

**Что это**:

 - Результат работы функции, который можно сохранить или использовать дальше.

 - Если не использовать `return`, функция вернёт `None`.

```python
def add_numbers(a, b):
    return a + b

result = add_numbers(5, 7)
print(result)  # 12
```
- `a` и `b` — аргументы

- `12` — возвращаемое значение
