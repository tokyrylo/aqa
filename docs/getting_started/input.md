# Ввод данных: `input()`

Компьютер сам не знает, что ты хочешь ему сказать.
`input()` — это способ попросить пользователя ввести что-то, а потом использовать это в программе.

Представь: ты подошёл к кассе и говоришь «Сколько мне яблок?» — касса ждёт твой ответ. В Python это делает `input()`.

## 1. Как это работает

```python
name = input("Введите ваше имя: ")
print("Привет,", name)
```
Что происходит:

- Программа выводит на экран текст: "Введите ваше имя:".

- Ждёт, пока ты что-то напечатаешь и нажмёшь Enter.

- Всё, что ты написал, сохраняется в переменную name.

- Потом программа использует это значение.

Пример работы:

```bash
Введите ваше имя: Ира
Привет, Ира
```

## 2. Ввод чисел

Важно: `input()` всегда возвращает строку.
Если нужна цифра, её нужно преобразовать в число:
```python
age = input("Сколько вам лет? ")
print(type(age))  # <class 'str'>
```
Чтобы получить число:

```python
age = int(input("Сколько вам лет? "))  # превращаем в целое число
print(age + 5)  # прибавляем 5 лет
```
Для числа с точкой (float):

```python
price = float(input("Введите цену пиццы: "))
print(price * 2)  # стоимость двух пицц
```

## 3. Примеры из жизни

1. Калькулятор чаевых:

```python
bill = float(input("Введите сумму счёта: "))
tip_percent = int(input("Введите % чаевых: "))
tip = bill * tip_percent / 100
print("Сумма чаевых:", tip)
```

2. Вопрос пользователю:

```python
likes_pizza = input("Вы любите пиццу? (да/нет): ")
print("Ответ пользователя:", likes_pizza)
```
