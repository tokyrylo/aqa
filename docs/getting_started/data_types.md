# Типы данных в Python

Тип данных = форма информации.
Представь, что у тебя дома разные коробки:

- В одной лежат **яблоки** (числа).

- В другой — **письма** (строки).

- В третьей — **лампочка: горит/не горит** (логические значения).

- А бывают коробки, где внутри ещё коробки (списки, словари).

## 1. Числа

**int — целые числа**

Без запятых.
Примеры: возраст, количество друзей, число лайков.

```python
age = 25
likes = 120
print(age + likes)   # 145
```

**float — числа с точкой**
Примеры: деньги, рост, температура.

```python
temperature = 36.6
salary = 1234.50
print(temperature + 1.2)   # 37.8
```

## 2. Строки (str)

Строка = текст в кавычках.
Примеры: имя, сообщение в чате, пароль.

```python
name = "Ира"
message = "Привет!"
print(name + " говорит: " + message)
```

Результат:

```bash
Ира говорит: Привет!
```

## 3. Логический тип (bool)

Может быть только два значения:

- `True` (правда)

- `False` (ложь)

Примеры: включён ли свет, зарегистрирован ли пользователь, идёт ли дождь.

```python
is_online = True
has_money = False
print("Пользователь в сети?", is_online)
```

## 4. Списки (list)

Список = коробка, где много значений подряд.
Примеры: список покупок, имена друзей, числа.

```python
fruits = ["яблоко", "банан", "киви"]
print(fruits[0])   # яблоко
print(len(fruits)) # 3 (количество элементов)
```

## 5. Кортежи (tuple)

То же, что список, но **нельзя менять**.
Пример: координаты GPS, дата рождения.

```python
birth_date = (2000, 5, 15)  # год, месяц, день
print("Год рождения:", birth_date[0])
```

## 6. Словари (dict)

Это как словарь в реальной жизни: «слово → значение».
Примеры: данные о пользователе, настройки программы.

```python
user = {
    "name": "Ира",
    "age": 25,
    "is_active": True
}
print(user["name"])   # Ира
```

## 7. Множества (set)

Набор уникальных значений (повторы убираются).
Пример: список посещённых городов.

```python
cities = {"Киев", "Львов", "Киев"}
print(cities)   # {'Киев', 'Львов'} — повтора нет
```

## 8. None (пустое значение)

`None` = «ничего нет».
Пример: пользователь ещё не ввёл email.

```python
email = None
print("Email:", email)   # Email: None
```

## 9. Дополнительные (более сложные)

- **bytes** — «сырые данные», например, файл в бинарном виде.

- **complex** — комплексные числа (редко нужны в AQA).

| Тип данных | Пример из жизни                      | В Python                               |
| ---------- | ------------------------------------ | -------------------------------------- |
| int        | количество шагов в фитнес-приложении | `steps = 10500`                        |
| float      | баланс на карте                      | `balance = 1234.56`                    |
| str        | сообщение в Telegram                 | `msg = "Привет!"`                      |
| bool       | включён ли свет                      | `is_light_on = True`                   |
| list       | список покупок                       | `shopping = ["хлеб", "молоко", "сыр"]` |
| tuple      | дата рождения                        | `birthday = (2000, 5, 15)`             |
| dict       | профиль пользователя                 | `user = {"name": "Ира", "age": 25}`    |
| set        | уникальные теги                      | `tags = {"python", "qa", "python"}`    |
| None       | нет данных                           | `phone = None`                         |
