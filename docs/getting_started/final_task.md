# Мини-упражнение: «Личный калькулятор»

**Цель упражнения**

1. Научиться создавать переменные разных типов: строки, числа, логические значения.

2. Научиться использовать арифметические, сравнения и логические операторы.

3. Научиться получать данные от пользователя через input().

**Задача**

Напиши программу, которая:

1. Спрашивает у пользователя:

  - Имя (строка)

  - Возраст (число)

  - Любит ли пиццу (логическое: да/нет)

2. Считает, сколько лет будет через 5 лет.

3. Проверяет, является ли пользователь взрослым (>=18 лет).

4. Выводит все данные красиво на экран.

## Подсказки

**Шаг 1: Ввод данных**

```python
name = input("Введите ваше имя: ")
age = int(input("Введите ваш возраст: "))
likes_pizza_input = input("Вы любите пиццу? (да/нет): ")
```

**Шаг 2: Логическое значение**

```python
likes_pizza = likes_pizza_input.lower() == "да"  # True если ответ "да"
```
**Шаг 3: Арифметика и сравнение**

```python
age_in_5_years = age + 5
is_adult = age >= 18
```

**Шаг 4: Вывод данных**

```python
print("Имя:", name)
print("Возраст:", age)
print("Через 5 лет будет:", age_in_5_years)
print("Вы взрослый?", is_adult)
print("Любите пиццу?", likes_pizza)
```
