# Операторы в Python

Оператор = действие над данными.
Например, в калькуляторе ты нажимаешь + или - → это и есть операторы.

В Python есть три главных группы:

1. **Арифметические** (сложение, вычитание и т.д.)

2. **Сравнения** (больше, меньше, равно)

3. **Логические** (и/или/не)

## 1. Арифметические операторы

Это как обычная математика:

```python
a = 10
b = 3

print(a + b)   # 13 (сложение)
print(a - b)   # 7  (вычитание)
print(a * b)   # 30 (умножение)
print(a / b)   # 3.333... (деление с остатком)
print(a // b)  # 3 (целая часть от деления)
print(a % b)   # 1 (остаток от деления)
print(a ** b)  # 1000 (возведение в степень: 10^3)
```

В жизни:

- Сколько будет 2 пиццы по 250 грн? → `2 * 250`.

- Остаток от деления зарплаты на 7 дней → `%`.

## 2. Операторы сравнения

Они отвечают на вопрос «да или нет» → результат всегда `True` или `False`.

```python
age = 18

print(age == 18)  # True  (равно)
print(age != 18)  # False (не равно)
print(age > 16)   # True  (больше)
print(age < 21)   # True  (меньше)
print(age >= 18)  # True  (больше или равно)
print(age <= 17)  # False (меньше или равно)
```

В жизни:

- Достиг ли человек совершеннолетия? (`age >= 18`)

- Яблок больше, чем груш? (`apples > pears`)

## 3. Логические операторы

Используются для работы с логическими значениями (`True/False`).

**and (И)**

Будет `True`, если оба условия истинны.

```python
is_adult = True
has_ticket = False

print(is_adult and has_ticket)  # False (нет билета)
```

**or (ИЛИ)**

Будет `True`, если хотя бы одно условие истинно.

```python
is_raining = True
has_umbrella = False

print(is_raining or has_umbrella)  # True (идёт дождь, даже без зонта)
```

**not (НЕ)**

Меняет значение на противоположное.

```python
is_light_on = True
print(not is_light_on)  # False
```

В жизни:

 - Человек взрослый и у него есть паспорт → можно войти.

 - На улице дождь или снег → берём зонт.

 - Свет не включён → темно.

## 4. Комбинации

Операторы можно соединять:

```python
age = 20
has_passport = True

print(age >= 18 and has_passport)  # True
```
