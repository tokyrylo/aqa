Строки

Строки — один из самых часто используемых типов данных в автоматизации тестирования. Мы работаем с текстом при:

  • проверке ответов API (JSON, XML, HTML),

  • обработке логов и сообщений,

  • генерации тестовых данных (номеров телефонов, email-адресов, сообщений).

Поэтому важно уметь уверенно работать со строками.

1. Создание строк

В Python строка может быть записана:

text1 = "Hello"
text2 = 'World'
text3 = """Многострочная
строка
с переводами строк"""

Одинарные и двойные кавычки равнозначны. Для многострочного текста используют тройные кавычки """ """.

2. Конкатенация (склеивание строк)

Конкатенация — это объединение строк через +.

first = "Quality"
second = "Assurance"

result = first + " " + second
print(result)  # Quality Assurance
  • Можно склеивать не только две строки, но и много:
info = "User: " + "test_user" + ", Status: " + "active"
print(info)  # User: test_user, Status: active

Недостаток: если строк много, код становится длинным и плохо читаемым.

3. F-строки (f-strings)

Это современный способ форматирования строк, который проще и удобнее конкатенации.

name = "Ольга"
age = 28
print(f"Имя: {name}, Возраст: {age}")
# Имя: Ольга, Возраст: 28

Преимущества f-строк: - Поддерживают выражения:

print(f"Через год будет {age + 1}")
# Через год будет 29
  • Можно форматировать числа:
pi = 3.1415926535
print(f"Число Пи с округлением: {pi:.2f}")
# Число Пи с округлением: 3.14

В автотестах f-строки — основной инструмент для формирования сообщений об ошибках и логов.

4. Разделение строк: .split()

Метод .split() делит строку на список частей.

text = "apple,banana,orange"
fruits = text.split(",")
print(fruits)  
# ['apple', 'banana', 'orange']

Частые применения в тестировании:

  • Разбить логи по строкам:
log = "ERROR: test1 failed\nOK: test2 passed"
lines = log.split("\n")
print(lines)  
# ['ERROR: test1 failed', 'OK: test2 passed']
  • Разделить строку по пробелам (по умолчанию):
words = "Hello world from Python".split()
print(words)  
# ['Hello', 'world', 'from', 'Python']

5. Замена в строке: .replace()

Метод .replace(old, new) заменяет подстроку.

message = "Hello QA!"
new_message = message.replace("QA", "AQA")
print(new_message)  # Hello AQA!

Пример из тестов: Очистка телефонного номера:

phone = "+38 (067) 123-45-67"
cleaned = phone.replace("(", "").replace(")", "").replace("-", "").replace(" ", "")
print(cleaned)  
# +380671234567

6. Полезные методы для AQA

  • .upper() — всё в верхний регистр:
"test".upper()  # TEST
  • .lower() — всё в нижний регистр:
"HELLO".lower()  # hello
  • .strip() — убирает пробелы и спецсимволы по краям:
"   test   ".strip()  # 'test'
  • .startswith() и .endswith() — проверка начала и конца строки:
"test_case.py".endswith(".py")  # True
