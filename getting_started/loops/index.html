Циклы

В тестировании часто нужно выполнять повторяющиеся действия:

  • прогонять тест для нескольких пользователей,

  • проверять список значений в API-ответе,

  • ждать появления элемента в UI.

Для этого в Python есть циклы.

1. Цикл for

Используется для перебора элементов коллекции (списка, строки, словаря, множества).

users = ["qa", "dev", "admin"]

for user in users:
    print(f"Тестирую логин для {user}")
  • Перебор строки:
for letter in "AQA":
    print(letter)
# A
# Q
# A
  • Перебор словаря:
response = {"status": "ok", "code": 200}

for key, value in response.items():
    print(f"{key}: {value}")

2. Цикл while

Выполняется, пока условие истинно.

counter = 0

while counter < 3:
    print(f"Попытка {counter + 1}")
    counter += 1

Пример для AQA: ожидание API-ответа

response_status = "processing"
attempts = 0

while response_status != "done" and attempts < 5:
    print("Ожидаем завершения...")
    attempts += 1
    # имитация смены статуса
    if attempts == 3:
        response_status = "done"

print("Статус:", response_status)

3. Оператор break

Прерывает выполнение цикла.

for num in range(1, 10):
    if num == 5:
        break
    print(num)
# 1 2 3 4

Пример для AQA: остановить тест при ошибке

tests = ["ok", "ok", "fail", "ok"]

for t in tests:
    if t == "fail":
        print("Тест упал! Останавливаю проверку.")
        break
    print("Тест прошёл:", t)

4. Оператор continue

Пропускает текущую итерацию и идёт дальше.

for num in range(1, 6):
    if num == 3:
        continue
    print(num)
# 1 2 4 5

Пример для AQA: пропустить невалидные данные

emails = ["qa@test.com", "", "dev@test.com"]

for email in emails:
    if email == "":
        continue  # пропускаем пустое значение
    print("Проверяю email:", email)

5. Полезный цикл for-else

else в цикле выполняется только если не было break.

for num in range(5):
    if num == 10:
        break
else:
    print("Число 10 не найдено")
