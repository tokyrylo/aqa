Коллекции в Python: списки, кортежи, множества и словари

В автоматизации тестирования часто приходится работать с набором данных: списком пользователей, параметрами API-запроса, результатами SQL-запроса или логами. Для этого в Python есть коллекции — специальные структуры для хранения и обработки данных.

Разберём четыре основных:

1. Списки (list)

Список — это упорядоченный изменяемый набор элементов.

users = ["alice", "bob", "charlie"]
print(users[0])  # alice

Основные операции:

# Добавление
users.append("david")  
# ['alice', 'bob', 'charlie', 'david']

# Вставка по индексу
users.insert(1, "eva")  
# ['alice', 'eva', 'bob', 'charlie', 'david']

# Удаление по значению
users.remove("bob")  
# ['alice', 'eva', 'charlie', 'david']

# Удаление по индексу
users.pop(0)  
# ['eva', 'charlie', 'david']

# Проверка наличия
print("eva" in users)  # True

Пример для AQA:

Храним тестовые данные для проверки логина:

test_users = ["user1", "user2", "user3"]
for user in test_users:
    print(f"Пробую логин с {user}")

2. Кортежи (tuple)

Кортеж — это упорядоченный, но неизменяемый набор элементов.

coordinates = (50.45, 30.52)  # Киев
print(coordinates[0])  # 50.45

Особенности:

  • Нельзя добавлять, удалять или изменять элементы.
  • Используются для фиксированных данных.

Пример для AQA:

Храним тестовые параметры, которые не должны меняться:

db_config = ("localhost", 5432, "test_db")

3. Множества (set)

Множество — это неупорядоченный набор уникальных элементов.

numbers = {1, 2, 3, 3, 2}
print(numbers)  # {1, 2, 3}

Основные операции:

a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # объединение → {1, 2, 3, 4, 5}
print(a & b)  # пересечение → {3}
print(a - b)  # разность → {1, 2}

Пример для AQA:

Проверка на дубликаты:

emails = ["qa@test.com", "dev@test.com", "qa@test.com"]
assert len(emails) != len(set(emails)), "Есть дубликаты email"

4. Словари (dict)

Словарь хранит пары "ключ → значение".

user = {"name": "Alice", "age": 25, "status": "active"}
print(user["name"])  # Alice

Основные операции:

# Добавление
user["email"] = "alice@example.com"

# Обновление
user["status"] = "inactive"

# Удаление
del user["age"]

# Проверка ключа
print("name" in user)  # True

Перебор словаря:

for key, value in user.items():
    print(f"{key}: {value}")

Пример для AQA:

Работа с JSON-ответом API:

response = {"user": "test_user", "status": "active"}
assert response["status"] == "active"
