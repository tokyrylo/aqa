Запуск программ в Python

Запуск готового файла с Python

Обычно мы пишем код в файлах. Давай создадим свою первую программу: 1. Откройте блокнот (или IDE — VS Code/PyCharm). 2. Напишите:

print("Hello! This is my first program")
  1. Сохраните файл как test.py (важно: расширение .py). Например, на рабочем столе.

Теперь запустим его через консоль:

  • Перейдём на рабочий стол:

  • Windows:

cd Desktop
  • macOS/Linux:
cd ~/Desktop
  • Запускаем:
  • Windows:
python test.py
  • macOS/Linux:
python3 test.py
  • Компьютер напечатает:
    Привет! Это моя первая программа.

📌 Мини-задание для закрепления:
1. Создай файл math.py.
2. Напиши в нём: 

   print(2 + 3)
   print(10 * 5)
   print("Сегодня я учу Python")
  1. Запусти через консоль.

Запуск Python в интерактивном режиме

Попробуем «поиграть» с Python прямо в консоли.

Введите:

python

Появится что-то вроде:

Python 3.11.6 (main, ...)
>>>

Три стрелки >>> — значит, мы внутри Python. Теперь можно писать команды!

Например:

print("Hello, world!")

Компьютер ответит:

Hello, world!

Чтобы выйти, напишите:

exit()

или нажмите Ctrl + Z (Windows) / Ctrl + D (macOS/Linux).
