Переменные и типы данных

Представь, что компьютер — это большой склад, а переменная — это коробка на складе. Ты можешь положить в коробку что угодно: число, слово, даже «правда/ложь». А потом обращаться к этой коробке по имени.

1. Что такое переменная

В жизни:

  • В телефоне у тебя есть контакт с именем “Мама”.

  • В этом контакте лежит номер телефона.

  • Имя — это «переменная».

  • Номер — это «значение».

В Python:

mama = "+380123456789"
print(mama)

Компьютер напечатает:

+380123456789

2. Типы данных

📌 Числа (int, float)

Это как в калькуляторе: можно складывать, умножать.

a = 5        # целое число (int)
b = 2.5      # число с точкой (float)

print(a + b)   # 7.5
print(a * 10)  # 50

📌 Строки (str)

Строка = текст. Всё, что в кавычках, — это строка.

name = "Ира"
print("Привет, " + name)

Результат:

Привет, Ира

📌 Логические значения (bool)

Это как «Да» или «Нет», «Правда» или «Ложь».

В Python всего два значения:

  • True (правда)

  • False (ложь)

is_raining = True
has_umbrella = False
print(is_raining)     # True
print(has_umbrella)   # False

Из жизни:

  • Включён ли свет? (True/False)

  • Есть ли деньги на карте? (True/False)

3. Зачем нужны переменные

Они позволяют хранить информацию и использовать её много раз.

Например, калькулятор чаевых:

bill = 500       # сумма счёта
tip_percent = 10 # чаевые
tip = bill * tip_percent / 100

print("Сумма чаевых:", tip)

Компьютер скажет:

Сумма чаевых: 50.0

Как называть переменные (Naming Convention)

1. Название должно быть информативным

❌ Плохо:

x = "Ира"
y = 25
z = True

Через неделю забудешь, что значит x, y и z.

✅ Хорошо:

user_name = "Ира"
user_age = 25
likes_pizza = True

Теперь сразу понятно: имя пользователя, возраст, любит ли пиццу.

Правила хорошего стиля (PEP8 — стандарт Python)

  • Только латиница (не имя, а name).

  • Используем snake_case (слова разделяются нижним подчёркиванием). Например:

  • user_name ✅

  • UserName ❌ (так в Python принято для классов, а не переменных).

  • Названия должны быть существительными (что это такое), а не глаголами.

Часто используемые суффиксы и префиксы

Чтобы сразу понять тип переменной по названию:

  • Для строк (str):
first_name = "Ivan"
last_name = "Petrenko"
message_text = "Hello"
  • Для чисел (int, float):
age = 25
price_usd = 19.99
order_count = 3
  • Для логических (bool): начинаем с is / has / can:
is_active = True      # активный ли пользователь
has_money = False     # есть ли деньги
can_login = True      # может ли войти

Ошибки, которых лучше избегать

❌ Не используем слишком короткие названия:

a = 100
b = 200
c = a + b

✅ Лучше:

product_price = 100
delivery_price = 200
total_price = product_price + delivery_price

❌ Не используем имена встроенных функций:

list = [1, 2, 3]   # плохо, list — это встроенный тип в Python

✅ Лучше:

numbers_list = [1, 2, 3]
