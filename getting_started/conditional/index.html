Условные конструкции в Python (if, elif, else)

В автоматизации тестирования часто нужно выполнять разные действия в зависимости от условий:

  • проверять статус ответа API,

  • анализировать результат логина,

  • сравнивать тестовые данные.

Для этого в Python используются условные конструкции

1. Базовый синтаксис

if условие:
    # выполняется, если условие истинно
elif другое_условие:
    # выполняется, если первое не сработало
else:
    # выполняется во всех остальных случаях

Важно: отступы в Python обязательны (обычно 4 пробела).

2. Простейший пример

status = "active"

if status == "active":
    print("Пользователь активен")
elif status == "blocked":
    print("Пользователь заблокирован")
else:
    print("Неизвестный статус")

3. Логические операторы

Можно проверять сразу несколько условий.

age = 25
country = "UA"

if age >= 18 and country == "UA":
    print("Разрешён доступ")

if age < 18 or country != "UA":
    print("Доступ запрещён")

if not age == 30:
    print("Возраст не равен 30")

4. Вложенные условия

response_code = 200
response_time = 120

if response_code == 200:
    if response_time < 500:
        print("API работает корректно")
    else:
        print("API отвечает слишком медленно")
else:
    print("Ошибка ответа от API")

5. Тернарный оператор

Краткая запись if-else.

status = "active"
message = "ОК" if status == "active" else "Ошибка"
print(message)  # ОК
